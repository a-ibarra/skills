# Context Quality Checklist

Use before reporting completion.

- Required files exist in `docs/codebase/`.
- Every output file starts with the verification stamp.
- Major claims include evidence paths.
- One end-to-end flow is fully traced with real files.
- `DOMAIN.md` exists only when domain vocabulary is non-trivial.
- `CONCERNS.md` exists when real risks or divergences are found.
- Unknowns are marked `[ASK USER]`.
- No secret values are copied into output docs.

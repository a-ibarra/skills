# Round-Based Interview

Ask only decisions that belong to the user. Look up facts yourself.

## Round 1: Purpose

- What failure does this skill prevent?
- Who hits that failure?
- Which existing skill is closest, and why is this different?

## Round 2: Scope

- What is in scope?
- What is explicitly out of scope?
- Which prompts should route somewhere else?

## Round 3: Triggers

- Which user phrases should fire this skill?
- Which similar phrases should not fire it?
- Which skill should fire instead for each should-not case?

## Output Rules

- Give one recommendation with each question.
- Keep question batches short.
- Stop when decisions are resolved.

# Working In This Repository

This repository ships marketplace-ready skills for Kerzon Studios.

## Rules

- Keep skill ids prefixed with `k-`.
- Keep folder name equal to frontmatter `name`.
- Keep instructions repository-agnostic unless explicitly documented otherwise.
- Keep the shared `## Execution` rule: nested agent first, inline only when
  unavailable.
- Do not add Python tooling in v1.

## Required Checks Before Claiming Done

- No unexpected org names in files.
- No `.py` files in the tree.
- Skill links resolve.
- Plugin/manifests and skill names stay consistent.
